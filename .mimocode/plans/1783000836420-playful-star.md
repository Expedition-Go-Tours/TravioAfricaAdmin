# Dashboard Overview Redesign Plan

## Design Direction

**Reading this as:** Analytics dashboard for a B2B SaaS platform (tour/experience marketplace), with a clean modern language, leaning toward refined Tailwind + Plus Jakarta Sans + restrained motion.

**Dial settings:** DESIGN_VARIANCE: 5 | MOTION_INTENSITY: 4 | VISUAL_DENSITY: 5

**Principle:** Preserve all business logic, API calls, routing, and state management. Only touch classNames, component structure, and visual presentation within `Overview.tsx`.

---

## Audit Findings

| Category | Issue | Severity |
|---|---|---|
| **Spacing** | Inconsistent gaps: `gap-2.5` (KPI/revenue) vs `gap-4` (other sections). Root `space-y-4 md:space-y-6` too tight. | High |
| **Cards** | Three different card patterns (KpiCard, RevenuePeriodCard, shared Card). No unified design language. | High |
| **Typography** | Page title too small (`text-lg`). KPI labels too small (`text-[11px]`). No display-sized numbers. All section headers identical weight. | High |
| **Visual Hierarchy** | All sections feel equal weight. No clear primary/secondary distinction. Revenue cards and KPI cards compete. | Medium |
| **Animation** | KpiCard and RevenuePeriodCard have no hover effects. Section cards have no entry animations. Stagger only on containers, not individual items. | Medium |
| **Responsiveness** | KPI grid jumps 2->3->4->7 columns. 7-col on xl is too tight. Inconsistent breakpoint usage across sections. | Medium |
| **Accessibility** | Missing aria-labels on clickable sections. Focus management gaps on list items. | Low |
| **Color** | Inconsistent surface-muted opacity values (`/20`, `/30`, `/40`). | Low |

## Changes (all in `src/pages/Overview.tsx`)

### 1. KpiCard Redesign (lines 808-854)

**Before:** Flat card with `border-l-2` accent, small `text-[11px]` labels, `text-base` values.

**After:**
- Remove `border-l-2` left accent border entirely - cleaner flat look
- Keep `rounded-xl bg-surface-base border border-border` base
- Increase value size: `text-lg md:text-xl font-bold` (was `text-base md:text-lg font-semibold`)
- Keep label: `text-[11px] md:text-xs font-medium uppercase tracking-[0.08em]` (unchanged, it's appropriate for KPI labels)
- Add hover effect: `hover:shadow-soft hover:-translate-y-0.5 transition-all duration-200`
- Icon container: keep existing `rounded-[10px]` with accent bg
- Keep all props, onClick, trend logic unchanged

### 2. RevenuePeriodCard Redesign (lines 856-872)

**Before:** Clean card (green bar already removed). `p-3.5 md:p-4`.

**After:**
- Increase padding to match KpiCard: `p-4 md:p-5`
- Increase revenue value size: `text-xl md:text-2xl font-bold` (was `text-lg md:text-xl`)
- Keep period label and commission/payout rows unchanged
- Add hover effect: `hover:shadow-soft hover:-translate-y-0.5 transition-all duration-200`
- No decorative elements (no bars, no gradients)

### 3. Root Container Spacing (line 243)

**Before:** `space-y-4 md:space-y-6`

**After:** `space-y-5 md:space-y-8` - more breathing room between sections

### 4. Page Header (lines 245-256)

**Before:** `text-lg md:text-xl font-semibold` with `border-l-2 border-l-primary` accent.

**After:**
- Remove the `border-l-2 border-l-primary` green left border on the title
- Increase title: `text-xl md:text-2xl font-bold tracking-tight`
- Keep back button unchanged

### 5. KPI Grid (line 265)

**Before:** `grid grid-cols-2 gap-2.5 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-7`

**After:** `grid grid-cols-2 gap-3 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-7`
- Slightly increase gap from 2.5 to 3 for better breathing
- Keep the 7-col xl breakpoint (it works with the compact KpiCard design)

### 6. Revenue Period Grid (line 341)

**Before:** `grid grid-cols-2 gap-2.5 lg:grid-cols-4`

**After:** `grid grid-cols-2 gap-3 md:grid-cols-2 lg:grid-cols-4`
- Match gap to KPI grid
- Add `md:grid-cols-2` for explicit intermediate breakpoint

### 7. Top Suppliers + Tours Grid (line 365)

**Before:** `grid grid-cols-1 gap-4 lg:grid-cols-3`

**After:** `grid grid-cols-1 gap-5 lg:grid-cols-3`
- Increase gap to 5 for section-level separation

### 8. Section Cards - CardHeader styling (lines 368, 415, 480, 530, 564)

**Before:** `<CardHeader className="border-b border-border pb-3">` with `<CardTitle className="flex items-center gap-2 text-sm font-semibold text-text-primary">`

**After:**
- CardHeader: `border-b border-border/60 pb-3.5` (softer border, slightly more padding)
- CardTitle: `flex items-center gap-2.5 text-[13px] font-semibold text-text-primary tracking-tight` (slightly smaller but tighter tracking for premium feel)
- Icon: keep `h-4 w-4 text-primary` unchanged

### 9. Bottom Grid (line 477)

**Before:** `grid grid-cols-1 gap-4 lg:grid-cols-2 xl:grid-cols-3`

**After:** `grid grid-cols-1 gap-5 lg:grid-cols-2 xl:grid-cols-3`
- Match gap to section-level spacing

### 10. Payout Summary Card (lines 575-590)

**Before:** Basic flex rows with `border-b border-border`.

**After:**
- Row styling: `flex items-center justify-between py-2.5 border-b border-border/60` (softer border)
- Keep all data and logic unchanged
- Button: keep existing `variant="outline" size="sm"` with arrow icon

### 11. Modal Shell (lines 705-737)

**Before:** Already well-designed with backdrop blur, animated panel, responsive mobile bottom sheet.

**After:** Minor refinements:
- Backdrop: keep `bg-black/40 backdrop-blur-sm`
- Panel: keep existing animation and styling
- No functional changes needed

### 12. WelcomeDashboard (lines 740-793)

**Before:** Has `border-primary/30 hover:border-primary/50 hover:shadow-tinted` on cards.

**After:** Keep as-is - it's a different context (permission-gated landing) and already well-styled.
